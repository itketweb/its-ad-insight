  • 사내망 또는 로그인 사용자만 열람

착수 전 필수 3

  1. Naver DA API현재 디스플레이 광고 플랫폼에서 API로 성과를 받을 수 있는지. 불가 시 리포트 파일 업로드로 대체할지권장 · 1차는 리포트 파일(CSV·엑셀) 업로드로 시작하고, 공식 API가 확인되면 같은 시트 형식으로 교체. 광고 관리 화면에서 API·리포트 메뉴 확인 필요
  2. 견적 데이터 접근ITKET·캐드코리아·ZbyHP·그룹웨어를 DB 조회 / 관리자 내보내기 / API 중 어떤 방식으로 가져올지확인됨 · 아이티켓은 견적이 접수될 때마다 쇼핑몰이 구글 시트(견적요청 리스트)에 한 줄씩 자동으로 쌓고 있음(2021-12부터). 대시보드는 이 시트를 읽으면 되어 쇼핑몰 소스 수정이 필요 없음. 캐드코리아·ZbyHP·그룹웨어는 같은 방식이 있는지 확인 필요
  3. 운영 위치·열람 방식사내 서버(사내망) 또는 로그인 기반 — 광고비가 외부에 노출되지 않는 방식권장 · 사내 서버(사내망 한정)에 정적 페이지로 올림. 페이지에 비밀키가 들어가므로 사내망 밖에서는 열리지 않게 하고, 키는 저장소에 올리지 않음

진행 중 결정 5

  1. 견적 유입 매체견적 접수 시 UTM·리퍼러가 저장되는지. 없으면 견적 폼에 숨은 필드 추가확인됨 · 유입경로는 2026-10-12부터 시트의 "유입 경로" 열에 쌓이기 시작함(쇼핑몰 DB에는 저장하지 않음). 그 전 견적은 "미수집"으로 표시
  2. 전환 정의견적 제출만인지, 전화 클릭 등도 포함인지
  3. Naver 스토어 금액쇼핑검색광고 비용인지, 스마트스토어 수수료·매출인지
  4. MDF지원금 금액의 출처와 입력 담당자
  5. “실시간” 기준1시간 단위 갱신이면 충분한지

항목상태확인된 것 · 막힌 이유할 일
Naver DA(GFA) API미확인브라우저 도구가 ads.naver.com·gfa.naver.com을 모두 막아 열지 못했고, 공개 문서에서도 API를 찾지 못함계정 화면의 리포트·API 메뉴 캡처 또는 광고 고객센터 문의 (사용자). 확인 전까지 리포트 파일 업로드로 구현
견적 · 아이티켓자동화 가능견적 접수 때마다 쇼핑몰이 구글 시트에 자동 적재 중(제목·접수날짜·영업담당·유입경로). 카테고리 열은 없어 제목 키워드로 분류. 쇼핑몰 소스는 수정하지 않음견적 시트 ID를 Apps Script 속성(QUOTE_SHEET_ID)에 입력하고 collectQuotes 실행 (사용자). 수집·집계 코드는 작성 완료 (Claude)
견적 · 캐드코리아 · ZbyHP · 그룹웨어일부 확인캐드코리아(cadkorea.co.kr)는. 나머지 고도몰 쇼핑몰은 HP·HPE 서버·워크스테이션 쇼핑몰이라 ZbyHP로 추정되나 도메인은 미확인. 그룹웨어 전화상담은 고도몰과 별개각 쇼핑몰 관리자의 개발 메뉴에 견적 리스트가 있는지 확인 (사용자 승인 후 Claude). 그룹웨어는 담당자 확인 필요 (사용자)
운영 위치 · 열람 방식결정 필요페이지에 비밀키가 들어가므로 외부 공개 호스팅은 부적합. 사내망 한정이 가장 단순페이지를 올릴 사내 PC·서버 지정 (사용자·사내 IT)
